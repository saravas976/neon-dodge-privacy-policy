1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки данных при использовании мобильного приложения Neon Dodge: Побег на машине.

Политика применяется ко всем пользователям приложения и регулирует вопросы, связанные со сбором, хранением, использованием и возможной передачей данных, которые могут обрабатываться в процессе использования игры.

Используя приложение, пользователь подтверждает, что ознакомился с настоящей Политикой конфиденциальности и принимает её условия.

2. Описание приложения

Neon Dodge: Побег на машине — это мобильная аркадная игра, в которой пользователь управляет автомобилем, уклоняется от препятствий, собирает монеты, выполняет задания, открывает новые машины и использует игровые улучшения.

Приложение предназначено для развлекательных целей и не требует создания аккаунта для использования основных функций.

3. Какие данные не собираются

Приложение не запрашивает и не собирает у пользователя следующие персональные данные:

  • имя, фамилию, отчество;
  • номер телефона;
  • адрес электронной почты;
  • паспортные данные;
  • адрес проживания;
  • банковские и платёжные реквизиты;
  • сведения о документах;
  • контакты из телефонной книги;
  • фотографии, видео и аудиофайлы пользователя;
  • личную переписку пользователя.

Разработчик не требует регистрации и не просит пользователя вводить перечисленные сведения для использования приложения.

4. Какие данные могут обрабатываться

Во время использования приложения могут обрабатываться только данные, необходимые для работы самой игры, в том числе:

  • количество монет;
  • выбранный автомобиль или скин;
  • игровые улучшения;
  • рекорд;
  • текущий прогресс;
  • состояние выполненных заданий;
  • ежедневный прогресс по миссиям;
  • настройки звука и другие игровые параметры.

Указанные данные используются исключительно для корректной работы приложения и сохранения игрового процесса.

5. Локальное хранение данных

Игровые данные, настройки и прогресс сохраняются локально на устройстве пользователя.

Разработчик не хранит эти игровые данные на собственных серверах и не использует удалённую базу данных для хранения пользовательского прогресса, если иное прямо не указано в новой версии приложения.

Если пользователь удалит приложение или очистит его данные, игровой прогресс может быть утерян.

6. Разрешения приложения

Приложение может использовать стандартные разрешения Android, необходимые для его работы, например:

  • доступ к сети Интернет — для загрузки и показа рекламы;
  • вибрация — для игровых эффектов.

Такие разрешения используются только в пределах функциональности приложения и не означают автоматический сбор персональных данных разработчиком.

7. Реклама и сторонние сервисы

В приложении может использоваться рекламный SDK третьих лиц для показа рекламы.

При работе рекламных сервисов автоматически могут обрабатываться технические данные, например:

  • информация об устройстве;
  • рекламные идентификаторы;
  • технические параметры приложения;
  • данные о показах, загрузке и взаимодействии с рекламой.

Такие данные могут обрабатываться соответствующими поставщиками рекламных сервисов в соответствии с их собственными правилами и политиками конфиденциальности.

Разработчик не контролирует полностью порядок обработки данных сторонними рекламными сервисами, но использует их только для обеспечения монетизации приложения.

8. Цели обработки данных

Данные, которые могут обрабатываться в приложении, используются для следующих целей:

  • обеспечение запуска и работы игры;
  • сохранение прогресса и игровых настроек;
  • отображение внутриигровых достижений, заданий и улучшений;
  • корректная работа рекламы;
  • улучшение стабильности и функциональности приложения;
  • исправление ошибок и технических неисправностей.

Данные не используются для продажи, навязывания услуг или иной деятельности, не связанной с работой приложения.

9. Передача данных третьим лицам

Разработчик не продаёт, не обменивает и не передаёт персональные данные пользователей третьим лицам.

При этом технические данные могут обрабатываться сторонними сервисами, встроенными в приложение, например рекламными платформами, если это необходимо для их работы.

Такая обработка осуществляется в рамках политики и условий соответствующих сторонних сервисов.

Разработчик принимает разумные организационные и технические меры для поддержания корректной и безопасной работы приложения.

При этом пользователь понимает, что ни один способ хранения данных на устройстве или передачи информации через сеть Интернет не может гарантировать абсолютную защиту от всех возможных угроз.

Приложение не предназначено для умышленного сбора персональных данных несовершеннолетних пользователей.
